# Caloriv Admin Portal: Operations, Nutrition & User Analytics Dashboard 📊

[![Caloriv Platform](https://img.shields.io/badge/Caloriv%20Ecosystem-caloriv--web.vercel.app-0070f3?style=for-the-badge&logo=vercel&logoColor=white)](https://caloriv-web.vercel.app)
[![Next.js](https://img.shields.io/badge/Next.js-15.0-000000?style=for-the-badge&logo=next.js&logoColor=white)](#)
[![TypeScript](https://img.shields.io/badge/TypeScript-5.0-3178C6?style=for-the-badge&logo=typescript&logoColor=white)](#)

The administrative control center for the **Caloriv** health and nutrition ecosystem. Provides operations teams and nutrition specialists with real-time insight into nutritional database records, user macro adherence, cohort metrics, and dietary telemetry.

---

## ⚡ Features

- 🥗 **Nutritional Database Management**: Full CRUD operations for regional and international food items, macro breakdowns, and verified allergen tags.
- 📈 **User Cohort Analytics**: Track active user engagement, daily logging compliance, and goal achievement rates.
- 🔒 **Role-Based Access Control (RBAC)**: Secure operator authentication and permission levels for medical reviewers.
- 🌐 **CORS & Proxy Hardening**: Configured for seamless API routing with the Caloriv core backend.

---

## 🛠️ Tech Stack

- **Framework**: Next.js (App Router), React, TypeScript
- **Styling**: Tailwind CSS, Lucide Icons
- **State & Hooks**: Custom context hooks for real-time telemetry
